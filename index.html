How I work

I built my own
team of AI agents

I built custom AI agents that handle the busywork around the design, and they work together. When I join a team, I learn how you already work first and fit in around it. A few of their skills:

1 · Editing

Video editing

I drop in raw footage. It comes back cut into clips, each one labeled with what happens in it, plus a rough first edit ready to open. Months later I can still search for any shot.

2 · Design

Design production

I design one main version. It gets turned into every size I need, like posts, stories, and banners, without rebuilding each one by hand, so they all match.

3 · Publishing

Social publishing

Finished posts get sized for each platform, get their captions, and get scheduled to go out on set days, so nothing sits finished and unposted.

4 · Updates

Project updates

Every decision and delivery gets written down in one place the moment it happens. Meetings go on the calendar automatically, and after a post goes live, the views and likes come back to me.

About

Visual Systems Designer

I build visual identities around one specific artist or brand, and the system that carries them.

That starts with the work people see: stage visuals, LED and VJ content, 3D logo animations, projection mapping, and branding. Every piece is made for that person, not pulled from a template.

It also covers the part people don't see: how every file is named, stored, and delivered, so anyone on the team can open the folder and know what to use. If there's already a brand system or a team in place, I start by learning how it works, then design within it and make it run smoother. I'm not there to tear it down.

Ten years with musicians, venues, and hospitality brands, usually running projects from first concept to final export on a deadline. I write my own tools so custom never means slow.
