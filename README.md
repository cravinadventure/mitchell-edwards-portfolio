# Mitchell Edwards - Portfolio

Personal portfolio for design hiring managers: multimedia and brand design work, motion,
social content, and the AI-accelerated content pipeline behind the practice. Plain HTML/CSS/JS,
no build step. Four case studies plus the flagship pipeline walkthrough, each framed
problem, process, outcome, and what the work did for the business.

Contact: cravinadventure@gmail.com

- `cravinadventure.com/cravinflavors` forwards to `/menu-photos/` (Cravin' Flavors app link).
